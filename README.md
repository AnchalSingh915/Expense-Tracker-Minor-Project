# Expense Tracker

## Project Description
Expense Tracker is a Python-based desktop application developed as a minor project. It helps users record and manage their daily expenses.

## Technologies Used
- Python
- Tkinter GUI
- Oracle Database
- python-oracledb
- PL/SQL

## Features
- Add expenses
- View saved expense records
- Delete selected expenses
- Refresh the expense table
- Display total expenses

## How to Run
1. Install Python.
2. Install the required database driver.
3. Configure the Oracle Database connection.
4. Run `main.py` in VS Code.
